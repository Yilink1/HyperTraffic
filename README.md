# 修复澎湃控制中心流量显示

[![LibXposed API 102](https://img.shields.io/badge/LibXposed-API%20102-brightgreen.svg)](https://github.com/libxposed/api)

解除 HyperOS 云控限制，恢复控制中心剩余流量显示

![效果对比](preview.jpg)

### 使用说明
1. 在 LSPosed 中启用本模块并勾选推荐作用域
2. 强行停止作用域应用即可生效

---
- **框架规范**：现代 LibXposed API 102 标准架构
- **极致纯净**：安装包仅 12KB，无后台进程、零耗电
